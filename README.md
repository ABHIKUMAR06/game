# Cubicle Justice

Unlimited 3D office slapstick. Design a cartoon boss, then slap, kick, cut hair, and spill coffee — every hit leaves a lasting mark. Neural English and Hindi voice packs with Play previews. No HR meter. No timer.

## Play locally

```bash
npm install
npm run dev
```

Opens on **http://127.0.0.1:4731**.

## Voice packs

On the title screen and customizer, tap **Play** on:

- English · Men / Women
- Hindi · Men / Women

Bundled neural MP3 samples play first; browser TTS is only a fallback.

## How to play

1. Listen to voice packs, then customize the boss in live 3D.
2. Deploy slap / kick / haircut / chicken / coffee / pie / stapler / void memo.
3. Marks stay for the whole session.
4. Meltdown score loops — play never fails on a timer or HR.

## Stack

Vite + React + TypeScript + Tailwind + Three.js. Reaction audio ships under `public/voice-samples/`.
